# Icons drawn in the Figma file

Heroicons has no drawing for these, so they come from John's Figma file
(`Shelbi`, fileKey `pu3hxHgWoCDPCzJ4u6zTQK`), exported from the Command
palette frame (2171:752) and drawn on its 20pt grid with the outline set's
1.25pt stroke. Each paints in `currentColor`.

- `toggle-off.svg`: the Zen Mode toggle (component 2220:24162).
- `toggle-on.svg`: the same drawing with the knob on the right, for
  "Turn Zen Mode off" (Figma draws only the off state).
- `page-curl.svg`: the error log (component 2236:24177).
- `flag-finish.svg`: Quit Shelbi (a filled drawing).
- `sidebar.svg`: the Toggle sidebar button (the Navigation component's
  titlebar, 2164:4; the collapsed sidebar's toggle in the main area).
