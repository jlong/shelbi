# Heroicons at 32pt

The launch window's folder (Figma "Startup · Projects and remote sessions",
2539:10949, and "Startup · No projects yet", 2544:10318) is the Heroicons
outline `folder` drawn at 32pt, exported from the frames on their 32pt grid:

- `folder.svg`: a project or remote session card's icon (the Horizontal
  Card's `Icon`, 2565:13582), the `24/outline` drawing scaled to 32pt, so its
  1.5pt stroke is 2pt.
- `folder-thin.svg`: the No projects yet state's (2544:10358), the same
  drawing with a 1.25pt stroke.

Each paints in `currentColor`.
