# Source Code Pro

The desktop's terminal typeface (Figma "Desktop/Terminal", 14 / 18). The four
TTFs come from Adobe's `adobe-fonts/source-code-pro` repository, `release`
branch at `803b7e23` (roman 2.042, italic 1.062):

- `SourceCodePro-Regular.ttf`, `SourceCodePro-Bold.ttf`
- `SourceCodePro-It.ttf`, `SourceCodePro-BoldIt.ttf`

Real bold and italic faces, so the terminal's SGR bold and italic never
synthesize. `LICENSE.md` is the SIL Open Font License 1.1 the fonts ship
under (Reserved Font Name "Source").
