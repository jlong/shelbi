# Symbols Nerd Font Mono

`SymbolsNerdFontMono-Regular.ttf` from the Nerd Fonts v3.4.0 release
(`NerdFontsSymbolsOnly.zip`, https://github.com/ryanoasis/nerd-fonts). The
terminal element uses it as a fallback for the private-use-area icons that
shell prompts and agents print (Powerline, Devicons, Codicons, Font Awesome,
Material Design, Octicons, and the rest), which no macOS system font covers.

`LICENSE` is the Nerd Fonts MIT license for the build. The glyph sets keep
their upstream licenses (Font Awesome: SIL OFL 1.1; Material Design Icons:
Apache 2.0; Codicons: CC BY 4.0; Octicons: MIT; and others), as listed in the
Nerd Fonts repository's `license-audit.md`.
