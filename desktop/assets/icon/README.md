# The app icons

Shelbi's desktop app has two icons, and the user picks between them in
Settings ▸ General ▸ App icon (`desktop.app_icon` in `~/.shelbi/config.yaml`):

- **Command Grille** (`command-grille`, the default and the app bundle's own
  icon): a layered macOS icon. A cobalt base, two light racing stripes, a
  floating dark glass oval grille, and a white `>_` terminal prompt.
- **Retro** (`retro`): the earlier raster icon, a cobalt and chrome tile with
  ivory stripes and a chrome-rimmed grille.

The bundle always wears Command Grille, so Finder, and the Dock before the
app launches, show it. The running app sets its Dock icon to the chosen one
(`NSApplication.applicationIconImage`, `src/platform/dock_icon.rs`) at launch
and the moment the user picks, and About (the desktop's and the TUI's) draws
the chosen one.

## What is here

| File | What it is | Made by |
|---|---|---|
| `Shelbi.icon/` | Command Grille's source: an Icon Composer document, four layers as SVG plus `icon.json` | exported from Figma (below) |
| `compiled/Assets.car` | Command Grille compiled: the layered icon macOS 26 draws with live glass, plus flattened 16 to 1024px renditions macOS 15 uses | `scripts/app-icon.sh` (actool) |
| `compiled/Shelbi.icns` | actool's flattened fallback, for whatever doesn't read the asset catalog | `scripts/app-icon.sh` (actool) |
| `compiled/Shelbi.icon.sha256` | digest of `Shelbi.icon/` when it was compiled | `scripts/app-icon.sh` |
| `command-grille-{512,224,128}.png` | Command Grille as macOS draws it (mask, glass, shadow) | `scripts/app-icon.sh` (rendered from the compiled icon) |
| `retro-1024.png` | Retro's master and only source | committed artwork (below) |
| `retro-{512,224,128}.png` | Retro cut down | `scripts/app-icon.sh` (`sips`) |

The PNGs are what the app draws itself, each at twice the points it is drawn
at (gpui samples a texture without mipmaps, so a larger picture drawn small
would alias): 512px for the Dock (its largest magnified size on a Retina
display), 224px for About's 112pt, 128px for the Settings tiles' 64pt. The
TUI's About draws half-block pixel art cut from `command-grille-512.png` and
`retro-1024.png` (`crates/shelbi-tui/src/overlay/about_icon.rs`, generated by
`scripts/tui-about-icon.py`).

`scripts/bundle.sh` copies `compiled/Assets.car` and `compiled/Shelbi.icns`
into `Shelbi.app/Contents/Resources` (the plist names them with
`CFBundleIconName` and `CFBundleIconFile`). It compiles nothing, so a release
build needs no Xcode 26, but it refuses to bundle when `Shelbi.icon/` no
longer matches `compiled/Shelbi.icon.sha256`, so an edited source can't ship
its old compile.

## Where they come from

**Command Grille** is concept 02 on the Figma frame
[Shelbi · Layered macOS icons · Round 2](https://www.figma.com/design/pu3hxHgWoCDPCzJ4u6zTQK/Shelbi?node-id=2379-20)
(column `2379:30`; preview symbol `2380:32`; size checks at 64, 32 and 16px
`2385:231`, `2385:248`, `2385:265`). Its source master is the 1024 x 1024
square, unmasked component
[App Icon / Layered / Command Grille / Source](https://www.figma.com/design/pu3hxHgWoCDPCzJ4u6zTQK/Shelbi?node-id=2380-20)
under "Unmasked masters" below the frame. Each of its four numbered layer
groups is one SVG in `Shelbi.icon/Assets/`, exported at 1024 x 1024:

| Layer | Figma group | File | In `icon.json` |
|---|---|---|---|
| 00 Base | `2380:21` (cobalt gradient) | `00-background.svg` | bottom group, no glass, no shadow |
| 01 Stripes | `2380:23` (two stripes, 72% ivory) | `01-stripes.svg` | no glass, no shadow |
| 02 Grille | `2380:26` (glass surround, indigo inset) | `02-grille.svg` | glass, translucent, neutral shadow |
| 03 Prompt | `2380:29` (chevron and cursor) | `03-prompt.svg` | glass, neutral shadow (top) |

The SVGs are Figma's exports with only Figma's page-background rectangles
and empty wrapper groups removed (they would paint the canvas color over
everything), and the base's gradient written in the layer's own
bounding-box units (`x1="0" y1="0" x2="0" y2="1"`): Figma exports it in user
space units, which actool draws as no fill at all. The colors and stops
(`#2996FC`, `#0962E5` at 48%, `#0641B8`) are Figma's. The system supplies the
corner mask, the edge highlights and the glass, as the frame's notes ask
("keep the source square; the system supplies the final corner mask").

**Retro** (`retro-1024.png`) was the app's icon before this one: the
[App Icon / Command Grille](https://www.figma.com/design/pu3hxHgWoCDPCzJ4u6zTQK/Shelbi?node-id=2366-9174)
component from the first round, generated raster artwork finished in Figma
with its macOS mask, framing and shadow over transparent corners, exported at
1024px (SHA-256
`591edeb18e39426e3c194f73e8684d961ea0298de9bd711bce8dc112d5075baf`). It is
committed as is; nothing renders it.

## Changing them

You need macOS with Xcode 26 or later (`xcode-select -p` pointing at it):
actool compiles Icon Composer's `.icon` format only from 26 on.

1. Command Grille: edit the layers in Figma, re-export the changed groups
   from the Source component at 1024 x 1024 as SVG, strip the page
   background as above, and replace them in `Shelbi.icon/Assets/`. Or open
   `Shelbi.icon` in Icon Composer (Xcode ▸ Open Developer Tool) to tune the
   glass, shadow and translucency, which it saves to `icon.json`.
   Retro: replace `retro-1024.png` with a 1024 x 1024 RGBA PNG and update its
   SHA-256 above.
2. Run `desktop/scripts/app-icon.sh`. It compiles `Shelbi.icon` into
   `compiled/`, renders Command Grille's PNGs from the compiled icon (through
   a throwaway, registered app so macOS draws it), cuts Retro's PNGs, and
   regenerates the TUI's tables.
3. Commit everything it wrote.
4. Check the result: `desktop/scripts/bundle.sh --no-build` (after a release
   build), then the app in Finder, the Dock and the app switcher, in light
   and dark, and each choice in Settings ▸ General ▸ App icon.
