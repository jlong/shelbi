# app-icon-racing-s: a third app icon, Racing S

## The change

Settings ▸ General ▸ App icon offers a third icon, **Racing S**
(`desktop.app_icon: racing-s`): a cobalt tile with a bold italic racing S in
porcelain white, offset over a translucent ice-blue copy of itself. Like
Command Grille it is a layered Icon Composer icon (`assets/icon/RacingS.icon`,
three SVG layers from the Figma Source component `2382:47`), so the system
supplies its corner mask, edge highlights, glass and shadow.

## How it works

- `shelbi_state::AppIcon::RacingS` (`racing-s`, label "Racing S"), last in
  `AppIcon::ALL`; `lenient_app_icon` reads `racing-s`, `racing_s`,
  `Racing-S`.
- `scripts/app-icon.sh` compiles each `.icon` with actool and draws it through
  a throwaway registered app (`compile_icon` / `draw_icon`). Command Grille's
  compile is committed (the bundle wears it); Racing S's stays in the scratch
  directory, since the app only draws its PNGs (`racing-s-{512,224,128}.png`).
  `bundle.sh` is unchanged.
- The desktop: `app_icon.rs` (About and tile images), `platform/dock_icon.rs`
  (the Dock's 512px picture: Racing S is never the bundle's icon, so it is
  always set as a picture).
- The TUI: `about_icon::RACING_S` (regenerated by `scripts/tui-about-icon.py`)
  for About; the General page's App icon row writes through the shared
  `shelbi_app::settings::general` form (`Change::AppIcon`,
  `GeneralForm::{app_icon, choose_app_icon, step_app_icon}`), as Theme does.
